# ตรวจบนมือถือก่อนยอมรับ Build 3.0

1. เปิดเว็บหลังอัปโหลด ต้องเห็น Build 3.0 RC และด่าน /12
2. เริ่มเกม ลากเล็ง ยิงตรงและชิ่งผนัง ตรวจเส้นสะท้อนกับจุดชน
3. เทียบแรงยิงและความหน่วงกับ Build 2.2 ที่แนบไว้
4. ไข่ปัจจุบันต้องอยู่หน้าตัว Tweety และ NEXT ต้องแสดงระหว่างยิงด้วย
5. ยิงกลุ่ม 3 ใบ และทำให้กลุ่มห้อยตก ตรวจคะแนน
6. เคลียร์ด่าน 1 และ 2 ตรวจการเปลี่ยนด่าน แล้วลองด่านท้ายเพื่อประเมินความยาก
7. ลูกบอล ↑ ต้องยกคานขึ้นเมื่อโดนยิง โบนัสไข่สั่นต้องแยกเป็นการฟัก Tweety
8. พักเกม ปิดหน้าจอ สลับแอป แล้วกลับมา ต้องไม่มีแรงกดดันเพิ่มระหว่างพัก
9. เริ่มใหม่ขณะข้อความ LEVEL CLEAR แสดง ต้องกลับด่าน 1 และไม่ถูกตัวจับเวลาเก่าพาข้ามด่าน
10. เปิด/ปิดเสียงในแนวตั้ง ปุ่มต้องแสดงครบ เสียงประกาศขึ้นกับเสียงภาษาอังกฤษของอุปกรณ์
11. ตรวจตัวละครทุกท่าว่ามีส่วนขอบถูกตัดหรือไม่ ภาพยังต้องเปลี่ยนเป็นพื้นโปร่งใสและตรวจลายหน้าอีกครั้ง
12. เล่นต่อเนื่อง 10 นาที สังเกตความร้อน อาการหน่วง และเสียงแตก

ยังไม่มีผลผ่านจากมือถือจริงสำหรับ Build 3.0 รายการนี้เป็นสิ่งที่ต้องตรวจ ไม่ใช่ผลทดสอบที่ทำแล้ว
